# NAMNIA

**Simple but Smart**

NAMNIA is a technology project focused on building smart marketing solutions for SMEs.

The goal is to help small and medium-sized businesses improve customer relationships, loyalty, marketing automation, analytics, and decision-making through software and AI.

## Vision

To make modern marketing technology simpler and more accessible for SMEs.

## Current Status

NAMNIA is currently in the learning, product design, and early development stage.
